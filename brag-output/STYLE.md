# Lyric-video style (approved)

Vertical 1080x1920, 30fps, built with Hyperframes (`full/` is the reference project).

- **Sync:** every word pops exactly when it is sung (word-level timing from ASR, aligned to the supplied transcript; fix by hand when a word is held).
- **Subtitles:** Hebrew translation pill under each line (Liberation Sans Bold, RTL), enters with the first word.
- **Sections:** top tag per section (flag/emoji + name), "Called to the stand" for countries, chorus on a bright "mirror" background with reflected text.
- **Pops:** flags and symbols pop on the spoken word with ring + sparks; count-up numbers; 1492 stamp.
- **Maps:** B&W world map behind the lyrics, camera zooms to the country and lights it gold (white-grey for Germany).
- **Motion:** mirror-wipe between sections, punch zoom, small shakes, flashes on list words, shine sweep on chorus, drifting orbs/beams, grain + vignette, audio-reactive glow, progress bar, "COURT ADJOURNED" end card.
- **Tone:** playful everywhere, sober for Germany (no extra effects).
- **Safe zone:** consider moving the top group down ~130px for Reels/TikTok.
