# media/ — תמונות וקטעי וידאו לכרטיסים

התיקייה הזאת ריקה, ובכוונה. הסרטון מתרנדר כמו שהוא גם בלעדיה.

## איך מוסיפים

שמור קובץ בשם **השנה של הכרטיס**, ותריץ שתי פקודות:

```bash
node build.mjs
npx hyperframes check && npx hyperframes render --output ../brag.mp4
```

`build.mjs` סורק את התיקייה הזאת, מוצא את הקבצים, ומחבר כל אחד לכרטיס שלו בתור
רקע (plate). אין מה לערוך ביד ב-`index.html` — הוא נוצר מחדש בכל הרצה.

| שם הקובץ | הכרטיס | מה לחפש |
|---|---|---|
| `1997.jpg` / `1997.mp4` | הסכם חברון | החתימה עם ערפאת בינואר 1997, או נתניהו בכנסת לפני ההצבעה |
| `1998.jpg` / `1998.mp4` | מזכר וואי | טקס החתימה בבית הלבן, אוקטובר 1998 — נתניהו, ערפאת, קלינטון, חוסיין |
| `2005.jpg` / `2005.mp4` | ההתנתקות | נתניהו שר האוצר בישיבת הממשלה, או הודעת ההתפטרות ב-7.8.2005 |
| `2009.jpg` / `2009.mp4` | בר-אילן | הנאום באוניברסיטת בר-אילן, 14.6.2009 |
| `2011.jpg` / `2011.mp4` | עסקת שליט | ההצהרה על העסקה, או הישיבה בקבינט, אוקטובר 2011 |
| `2013.jpg` / `2013.mp4` | 104 אסירים | נתניהו על המו״מ עם קרי, יולי 2013 |

פורמטים: `jpg` `jpeg` `png` `webp` `mp4` `webm`. אם יש גם תמונה וגם וידאו לאותה
שנה — הווידאו מנצח.

## מה קורה לקובץ אחרי שמוסיפים אותו

הוא יושב **מאחורי** הטקסט, לא במקומו: שחור-לבן, מוחשך ל-50%, שקיפות 40%, ומעליו
שכבת הצללה שמתחזקת כלפי מטה. זה מכוון — הכרטיס חייב להישאר קריא בטלפון גם כשמתחתיו
פריים בהיר. תמונות סטילס מקבלות תנועת מצלמה איטית (1.06 → 1.15 לאורך 6.5 שניות);
קטעי וידאו לא, כי יש להם תנועה משלהם.

קטעי וידאu מושתקים (`muted`) — הסרטון בנוי בלי קריינות, והקול המקורי יתנגש עם
הקצב של הכרטיסים. אם אתה כן רוצה משפט מקורי נשמע, תגיד לי ואסדר את זה נכון: זה
דורש להאריך את הכרטיס ולהוריד את האפקטים סביבו.

## לפני שאתה מוריד חומר

**אני לא יכול להביא את זה בשבילך.** מדיניות הרשת של הסביבה הזאת חוסמת את כל
מקורות המדיה (ויקישיתוף, ארכיון האינטרנט, יוטיוב, לשכת העיתונות הממשלתית) — כל
בקשה חוזרת ב-403. גם אם לא הייתה חסומה, צילומי חדשות וארכיון מ-1997–2013 הם חומר
מוגן, וההחלטה לפרסם סרטון פוליטי שבנוי עליהם היא שלך, לא שלי.

שתי נקודות מעשיות:

1. **שימוש הוגן לצורך ביקורת** (סעיף 19 לחוק זכות יוצרים) הוא דוקטרינה אמיתית,
   והסרטון הזה הוא בדיוק ביקורת על יצירה אחרת. זה לא אומר שאתה מחוסן — זה אומר
   שיש לך טיעון. אם הסרטון הולך לרוץ בהיקף רציני, שווה לשאול עורך דין ולא אותי.
2. **גם כשהחוק לידך, Content ID לא מתעניין.** יוטיוב ומטא יסמנו קטעים מזוהים
   אוטומטית, ויכולים להשתיק או לחסום את הסרטון בלי קשר לשאלה המשפטית. קטעים
   קצרים (2–4 שניות), שחור-לבן ומוחשכים כמו כאן, נתפסים פחות — אבל לא אפס.

מקורות שכדאי לבדוק קודם: לשכת העיתונות הממשלתית (חלק מהתצלומים ברישיון פתוח),
ערוץ הכנסת, ויקישיתוף, וארכיוני חדשות שמוכרים רישיון לשימוש.
