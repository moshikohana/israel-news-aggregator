# תשובה לבקוביץ׳ — סרטון 60 שניות

מענה עובדתי לסרטון שבו יינון בקוביץ׳ מציג מצגת ובה שבע-שמונה "שקופיות" שנועדו להוכיח
שנתניהו הוא "הכי שמאלני מכולם". כל שקופית אצלו נכונה וחלקית; הסרטון הזה מחזיר לכל אחת
מהן את החלק שהושמט.

| קובץ | מה יש בו |
|---|---|
| `brag.mp4` | הסרטון המוגמר — אנכי 9:16, 60 שניות |
| `brag.jpg` | תמונת הכריכה (גם צרובה כפריים 0 של ה-MP4) |
| `script.md` | התסריט לפי סצנות, דף עובדות עם מקורות, ומה הושאר בחוץ ולמה |
| `share-copy.txt` | טקסט מוכן לפוסט, גרסה קצרה, והערות לפני פרסום |
| `brag-plan.md` | הסטוריבורד, החלטות הטון והאודיו |
| `composition/` | מקור הסרטון (HTML + GSAP, Hyperframes) |

## לבנות מחדש

```bash
cd composition
npx hyperframes check      # חייב לעבור עם 0 שגיאות
npx hyperframes render --output ../brag.mp4
```

הפונטים (Heebo) ו-GSAP נשמרו מקומית תחת `composition/assets/`, כדי שהרינדור יהיה זהה
בכל הרצה ולא יהיה תלוי ברשת.

## שתי הערות שכדאי לקרוא לפני שמפרסמים

1. **כספי קטר (2018) לא נכללו בסרטון.** הטענה של בקוביץ׳ נכונה, וההגנה המקובלת דורשת
   מקור מסודר. בלי מקור — עדיף להשאיר בחוץ מאשר לנסח במעורפל.
2. **הסרטון עונה על הסעיפים, לא על הדפוס.** הטענה החזקה נגדו היא שגם אם כל סעיף מוסבר,
   נשאר פער בין רטוריקה ימנית למעשים שכוללים ויתורים. כדאי לדעת את זה מראש.

פירוט מלא ב-`script.md`.
