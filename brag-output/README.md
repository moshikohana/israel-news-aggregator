# תשובה לברקו — סרטון 60 שניות (גרסה 3)

מענה עובדתי לסרטון שבו ברקו מציג מצגת שנועדה להוכיח שנתניהו הוא "הכי שמאלני
מכולם".

**הגישה:** לא מתווכחים עם השקופיות — מקבלים את כולן, ותוקפים את המסקנה. הסרטון
נפתח בקליפ שלו ובמשפט "ברקו צודק. כל תשע השקופיות.", מראה את המצגת שלו מהמסך שלו,
ואז עונה כרטיס-כרטיס על שש השקופיות הנושאות. מסיים בשקופית שלא הייתה שם בכלל:
מדינה פלסטינית לא קמה.

**שתי תיקוני עובדה מהקליפ ששלחת:** המצגת שלו מונה **תשע** שקופיות (לא שבע), והשם
על הגרפיקה שלו הוא **ברקו**. שניהם תוקנו בכל הקבצים.

## להוסיף קטעים של נתניהו

התשתית מוכנה ומחכה לקבצים. שומרים קובץ לפי שנה (`1997.jpg`, `2009.mp4`...) בתוך
`composition/media/`, ומריצים:

```bash
cd composition
node build.mjs          # מזהה את הקבצים ומחבר כל אחד לכרטיס שלו
npx hyperframes check
npx hyperframes render --output ../brag.mp4
```

כל קובץ נכנס כרקע מאחורי הטקסט — שחור-לבן, מוחשך, עם שכבת הצללה — כדי שהכרטיס יישאר
קריא בטלפון. פירוט מלא, כולל מה לחפש לכל שנה: `composition/media/README.md`.

**את הקטעים של נתניהו צריך להביא ידנית.** מדיניות הרשת של סביבת העבודה מחזירה 403
לכל מקור מדיה (יוטיוב, ויקישיתוף, ארכיון האינטרנט, לשכת העיתונות הממשלתית). רשימת
הקניות — איזה קטע לכל שנה ומה לחפש — נמצאת ב-`composition/media/README.md`, יחד עם
ההערה על זכויות יוצרים ו-Content ID.

## לבנות מחדש

```bash
cd composition && node build.mjs && npx hyperframes check && npx hyperframes render --output ../brag.mp4
```

הפונטים (Heebo) ו-GSAP שמורים מקומית תחת `composition/assets/`, כך שהרינדור זהה בכל
הרצה ולא תלוי ברשת.
