# נכסים קבועים לטפט

התיקייה הזו ריקה בכוונה. כל קובץ שמפילים על העמוד נשמר ב-IndexedDB של
הדפדפן ולא עובר לכאן - זה נוח, אבל זה חי רק במכשיר אחד.

אם רוצים שהדמות תגיע לכל מקום (גם לטלפון, גם ל-GitHub Pages, גם אחרי
ניקוי הדפדפן) - שמים כאן את הקבצים ומוסיפים `manifest.json`:

```json
{
  "actor": "girl.webm",
  "bg": "beach.mp4",
  "actorConfig": { "scale": 1.3, "offsetY": 20, "handsY": 0.82 },
  "bgConfig": { "scale": 1.05 }
}
```

`actorConfig` ו-`bgConfig` הם אופציונליים - אלה אותם ערכים שמכוונים
בחלונית 🖼️ בתוך האפליקציה. הכי פשוט: לכוון שם עד שזה נראה טוב, לפתוח
את קונסולת הדפדפן ולהריץ
`localStorage.getItem('live-wallpaper-photo-actor')`, ולהדביק את התוצאה
לכאן.

קובץ שהמשתמש מעלה בעצמו תמיד גובר על מה שיש כאן.

איך מייצרים את הקבצים - ב-`PHOTOREAL.md` בשורש הריפו.
